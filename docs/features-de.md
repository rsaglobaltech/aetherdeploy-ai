# AetherDeploy: Projekt-Features (Kurzfassung)

- Deployment per natürlicher Sprache oder Befehlen.
- Multi-Cloud: AWS, GCP, Azure.
- Umgebungen: `local`, `feature`, `prod`.
- Human-in-the-Loop vor kritischen Änderungen.
- Auto-Erkennung des Tech-Stacks + Terraform/Compose-Generierung.
- KI-Kostenoptimierung und interaktive TUI (Text User Interface).
